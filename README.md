# Kidney_Atlas

This repository contains the integration and analysis notebooks and results for the Human Cell Atlas Kidney (HCKA).

## Interactive 3D UMAPs

- [HCKAsc_3DUmap.html](HCKAsc_3DUmap.html) — single-cell 3D UMAP
- [HCKAsn_3DUmap.html](HCKAsn_3DUmap.html) — single-nucleus 3D UMAP

> 1. Open via [htmlpreview.github.io](https://htmlpreview.github.io) — prefix the raw GitHub URL, e.g. `https://htmlpreview.github.io/?https://raw.githubusercontent.com/zhou119010475/Kidney_integration/main/HCKAsc_3DUmap.html`, or
> 2. Enable [GitHub Pages](https://pages.github.com/) for this repo (Settings → Pages → deploy from `main`), then browse to `https://zhou119010475.github.io/Kidney_integration/HCKAsc_3DUmap.html`.
